# 📊 Sales Analysis Dashboard

## 📌 Project Overview
This project showcases an interactive **Sales Analysis Dashboard** built using **Power BI**. It transforms raw sales data into meaningful insights through dynamic visualizations, helping businesses track performance and make informed decisions.

---
## 🎯 Key Highlights (Recruiter Focus)
- ✔ Built end-to-end data dashboard using Power BI  
- ✔ Applied data cleaning, transformation, and DAX  
- ✔ Designed interactive UI with slicers and KPIs  
- ✔ Delivered actionable insights on sales trends and performance  
- ✔ Demonstrates strong data analytics & visualization skills  

---
## 📊 Features
- 📌 KPI Metrics: Total Sales, Profit, Quantity  
- 📈 Time-based Analysis (Monthly / Yearly Trends)  
- 🌍 Region-wise Sales Performance  
- 📦 Product Category Insights  
- 🎯 Interactive Filters & Slicers  

---
## 📂 Dataset
The dataset includes:
- Sales Transactions  
- Product Categories & Subcategories  
- Customer Segmentation  
- Regional Data  
- Order Date & Revenue Metrics  

---
## ⚙️ Tech Stack
- Power BI Desktop  
- Power Query (ETL)  
- DAX (Data Analysis Expressions)
